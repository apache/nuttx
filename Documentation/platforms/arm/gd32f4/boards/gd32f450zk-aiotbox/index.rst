==================
gd32f450zk-aiotbox
==================

.. tags:: arch:arm, chip:gd32f4, vendor:gigadevice

The GD32F450Z-AIOTBOX board is a Xiaomi AIoT development platform U1
control board that uses the GD32F450ZK chip as the core.
