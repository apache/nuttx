# Documentation/platforms/chip-vendors.txt
#
# Who makes each chip family, so that the vendor: tag on a board page can be
# derived rather than typed.  Checked by tools/ci/check_doc_coverage.py.
#
# One rule per line:
#
#   <family>   <vendor>      exact family, named after the directory under
#                            arch/<arch>/src/
#   <prefix>*  <vendor>      every family starting with <prefix>
#   <family>   -             no vendor: virtual, emulated or open source
#   <family>   ?             vendor not known to us yet; see the note below
#
# Exact rules win over prefix rules; the longest prefix wins.  The vendor name
# is lower case, no spaces, and names the company as it is today: Freescale
# parts are nxp because Freescale became part of NXP in 2015.
#
# A chip family with no rule here makes the check fail.  That is deliberate:
# adding a family is the moment somebody knows who makes it.
